# 旧資料の保管場所

旧マニュアル・ドラフト・PDF・制作記録・開発技術資料は、この `docs/OLD/` 以下へ元の構成を維持して保管しています。

- 正規版の操作ガイド：[../manual/index.html](../manual/index.html)
- 正規版のレシピ集：[../manual/recipes.html](../manual/recipes.html)
- `docs-archive-manifest-2026-10-27.json` に元の691ファイルの相対パスとSHA-256を記録しています。移動後も原本と一致することを検査しています。
- 保管した古い制作スクリプトは移動前のパスを前提とする履歴です。現在の検査には、プロジェクト直下の `tools/manual/` を使用してください。

旧マニュアル本体・ドラフト・PDF・ローカル検証記録はローカル保管対象です。リポジトリには旧技術資料と旧スクリーンショットを保存し、現在の公開用資料は `docs/manual/` に配置します。
